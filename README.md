# 星潮 / STARFALL

Godot 4.7.2 制作的独立纵版弹幕射击原型。方向键移动、向上连射、精确移动、限次消弹，穿越敌机编队并击破多阶段 Boss。不是竞技场近战游戏。

## 运行
1. 使用 Godot 4.7.2 打开 `project.godot`。
2. 按 F6/F5 运行主场景，点击「开始出击」或按 Enter。
3. 无插件、无联网、无需下载素材。

## 操作
- WASD / 方向键：移动。
- Shift：低速精确移动，并显示白色中心判定点。机翼不会被命中。
- 默认自动向上连射；F 切换自动射击；Z 手动射击。
- X / Space：星潮脉冲，消除敌方弹幕并造成伤害。次数有限。
- Esc / P：暂停或继续。窗口失焦自动暂停。
- 暂停或结束后 R：重新开始；结束后 Enter：再次出击。
- M：声音开关。V：降低背景动效。

## 内容
- 单人离线完整流程，生命、分数、武器强化、敌机编队与三阶段 Boss。
- 精确命中点、受伤保护、炸弹救场、爆炸与原创提示音。
- 金色 P 拾取物提升火力，B 补充炸弹；接近时吸附，在战场上部可全屏回收。
- 初始 3 条生命和 3 枚炸弹，最多各 5；达到 25000 分可获一次额外生命。
- 全幅战场：1440×960 基准，整个窗口都是游戏画面，无左右侧栏。
- 顶部轻量 HUD 只显示分数、生命、脉冲次数与暂停按钮；Boss 出现时显示阶段与血条。
- 操作提示只在开始 / 暂停 / 结束画面显示，战斗中不常驻教程或调试文字。
- 宽屏与竖屏采用等比画布扩展，不拉伸飞船、弹幕或命中点；编队、Boss 巡航和移动边界随战场尺寸适配。调整窗口会同步映射现有实体位置，保持相对位置。
- 所有美术与声音均随工程提供，不使用外部联网资源。

## 项目结构
- `scripts/game_core.gd`：纯逻辑模拟、敌机/弹幕/碰撞/胜负。
- `scripts/main.gd`：画面、键盘与鼠标交互、音效和暂停。
- `scenes/main.tscn`：默认入口。
- `tests/`：无界面回归测试。
- `ART_SOURCES.md`：素材来源及许可。

## 敌机角色与刀刃弹幕编排（2026-10-27）

保留获批的透明能量符号、彩色细亮边、非像素化曲线尾迹、全幅自适应战场与最简 HUD。现有键位、生命 / 脉冲规则、86 秒 Boss 到场时间不变；本节的弹幕规则取代前文“玩法未改”的历史说明。

- **狙击符号 / sniper**：上方停驻，锁定方向并停顿 0.7 秒后，连续两次三发针形扇射（间隔 0.25 秒），随后休息 2.3 秒。停顿和短连射中不再追踪玩家。
- **横扫符号 / sweeper**：上方横向往返，停顿 0.5 秒后以三次双翼扇射扫过战场（间隔 0.34 秒），中间保留逃生通道，休息 2.1 秒。
- **环轨符号 / orbiter**：小幅绕行，停顿 0.7 秒后发射两轮有缺口的扩散环（间隔 0.45 秒），缺口朝向锁定时的位置，半角 0.48 弧度；休息 2.5 秒。
- 新敌机 7 秒后向上退场，9 秒清理，不从下方或左右边缘突然撞入。普通敌机距玩家不足 140 px 时禁止发射；每个编队按序错开起手。

### 关卡教学顺序

波次仍从 1.8 秒开始，每 8 秒一波：侦察机 → 单狙击 → 单横扫 → 单环轨 → 双狙击夹侦察 → 横扫与编织机 → 环轨与炮手 → 狙击 / 横扫 / 侦察 → 环轨与编织机 → 狙击 / 炮手 / 横扫 → 环轨 / 侦察 / 狙击。86 秒切换 Boss 时清场，保留入场与阶段切换安全窗口。

### Boss 刀刃与节拍

六片刃及分段弧由模拟中的 `rotation` 驱动，中心命中场不随装饰偏移。角速度以指数缓动在休息和攻击速度间切换，三阶段旋向 / 强度不同；暂停冻结，重开归零。实际子弹从对应的**旋转刀尖**发射，使用有界角速度形成真正弯曲的轨迹，不只是画出弯尾迹。

每个 7.2 秒循环：0 秒锁定瞄准 → 0.55 / 0.95 秒刀尖短扇射 → 2 秒锁定缺口方向 → 2.75 / 3.45 秒刀尖弧环（第三阶段另有 4.15 秒一轮）→ 停火到下一循环。弧环预留较宽缺口，曲率温和，离开屏幕和超时子弹仍会清理；没有独立计时器互相叠加随机喷射。

## 当前玩法：路径分段、弹体职责与 Boss 乐句（2026-10-27）

本节取代上文旧版移动与 7.2 秒 Boss 循环说明；透明能量符号、彩色细边、全幅最简 HUD、正常操作规则与**无显式预警**保持不变。

- 所有普通敌机采用确定性进入 / 攻击 / 退场路径，Hermite 段共用端点切线；2.1 秒进入攻击段，狙击 5.4 秒退场、其余 6.4 秒，8.8 秒清理。横扫从侧面进入、浅 S 横穿并从另一侧离开；狙击斜弧减速、锁定短连射后向外退；环轨局部椭圆按相位射击、沿切线离开。侦察编队使用共享曲线和镜像 / 错峰，不再硬钳停或随机抖动。最多 ±0.30 弧度的缓动侧倾由实际横向速度驱动。
- 弹幕分职责：少量小针弹半径 3.5、速度 290；中型主流弹半径约 6、速度 160–185；少量大弧月障碍半径 10、速度 95（逻辑 px/s）。碰撞仍使用明确圆形核心；透明光晕、弧月外形和色带不扩大判定。
