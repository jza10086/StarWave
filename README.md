# 星潮

个人赛 2–8 人同一战场；团队赛 2/4/6/8 人分为两个独立战场，以全队生存时长排名。

默认 180 秒，3 生命、3 炸弹。击败敌人 +100、每次受伤 −200、Boss 每点有效伤害 +1；负分允许。归属最后造成击败的玩家，Boss 伤害按实际扣除量计算。普通拾取只增强火力/炸弹，不额外加分。个人赛 Boss 击败/全部阵亡/时限结束后按分数排名。团队按座次交错均分；相同波次，Boss 击败后进入更强的新循环，最后一人阵亡即停止该队计时；时限双方仍生存则并列。队员无碰撞和友伤，炸弹与护盾影响本战场弹幕；两战场互不影响。WASD、Shift 精确移动、X 炸弹、空格射击，默认自动射击。团队默认放大自己的战场，可切换双战场总览，双方生存时长始终显示。1440×960 固定逻辑场地，窗口只缩放。主机 120 Hz 模拟与伤害结算，压缩快照 10 Hz，本地显示做短时外推，死亡玩家观战；弱网手感仍需人工验收。

API 4 / manifest 2，普通 standard 排名协议。由原版小游戏轮换大游戏选择本包即可测试。协议、大游戏和所有已选小游戏的有效人数取交集；星潮团队模式会收窄为偶数。房间规则使用本包 config_schema；高级设置创建的预设仍走框架草稿/应用/保存流程。局内没有重开或单独暂停，切出窗口不会暂停计时。原型保留在 tmp，此包不依赖原型目录。

自动化：tests/original_arcade_rules_test.gd（规则、清单、人数）和 tests/original_arcade_network_test.gd（正式大厅、轮换、4/5 个 ENet 端、UI 回调和结算）。真实键鼠、多窗口手感及外网仍需人工检查。
