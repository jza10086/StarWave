# 星潮 / STARFALL

Godot 4.7.2 制作的独立纵版弹幕射击原型。方向键移动、向上连射、精确移动、限次消弹，穿越敌机编队并击破多阶段 Boss。不是竞技场近战游戏。

## 运行
1. 使用 Godot 4.7.2 打开 `project.godot`。
2. 按 F6/F5 运行主场景，点击「开始出击」或按 Enter。
3. 无插件、无联网、无需下载素材。

## 操作
- WASD / 方向键：移动。
- Shift：低速精确移动，并显示白色中心判定点。机翼不会被命中。
- 默认自动向上连射；F 切换自动射击；Z 手动射击。
- X / Space：星潮脉冲，消除敌方弹幕并造成伤害。次数有限。
- Esc / P：暂停或继续。窗口失焦自动暂停。
- 暂停或结束后 R：重新开始；结束后 Enter：再次出击。
- M：声音开关。V：降低背景动效。

## 内容
- 单人离线完整流程，生命、分数、武器强化、敌机编队与三阶段 Boss。
- 精确命中点、受伤保护、炸弹救场、爆炸与原创提示音。
- 金色 P 拾取物提升火力，B 补充炸弹；接近时吸附，在战场上部可全屏回收。
- 初始 3 条生命和 3 枚炸弹，最多各 5；达到 25000 分可获一次额外生命。
- 全幅战场：1440×960 基准，整个窗口都是游戏画面，无左右侧栏。
- 顶部轻量 HUD 只显示分数、生命、脉冲次数与暂停按钮；Boss 出现时显示阶段与血条。
- 操作提示只在开始 / 暂停 / 结束画面显示，战斗中不常驻教程或调试文字。
- 宽屏与竖屏采用等比画布扩展，不拉伸飞船、弹幕或命中点；编队、Boss 巡航和移动边界随战场尺寸适配。调整窗口会同步映射现有实体位置，保持相对位置。
- 所有美术与声音均随工程提供，不使用外部联网资源。

## 项目结构
- `scripts/game_core.gd`：纯逻辑模拟、敌机/弹幕/碰撞/胜负。
- `scripts/main.gd`：画面、键盘与鼠标交互、音效和暂停。
- `scenes/main.tscn`：默认入口。
- `tests/`：无界面回归测试。
- `ART_SOURCES.md`：素材来源及许可。

## Neon Geometric 美术
- 深蓝紫星域、缓慢轨道弧与低对比几何碎片，取代轨道甲板网格。
- 玩家青色锐角飞船与双喷口拖尾；敌机按类型使用三角、菱形、六边形，Boss 使用多层六边装甲、轨道核心与独立侧模块。
- 青色友方射线、暖粉 / 橙色及紫色敌弹、金色 P/B 拾取物；危险弹体有清晰实色边缘，不用视觉辉光扩大判定。
- 同心冲击环、空心三角爆散、受控线条光晕，最小化 HUD 统一霓虹细边。
- 美术重制不改变碰撞、速度、弹幕、Boss 阶段、输入或关卡规则。V 继续关闭背景动效。
- 原创程序几何；风格研究出处与素材说明见 `ART_SOURCES.md`。

## 渐变与柔光精修
- 连续蓝紫深空 Shader，微量抖动避免 8-bit 色带；V 可冻结漂移。
- 连续 Gaussian 加色光晕、渐变装甲内芯与细锐轮廓，取代硬边多层线框光带。
- 双喷口与友方射击使用收细、衰减的渐变尾迹，冲击波使用平滑环形能量衰减。
- 软光层在实体后方：暖色危险弹体、玩家白色 4 px 判定点仍清晰。规则与输入不变。
- 纹理仅启动时生成并复用；无全屏 bloom 模糊链，无新增第三方资产。
